# ドクダミすごろく 🌿🎲

就活すごろくと、人生ゲーム風の遊び用すごろくを切り替えられるWebアプリです。

## ページ構成

- `index.html` — タイトル・モード選択
- `job.html` — 就活すごろく。相談マスでは50%の確率で「スッキリ！」または「ストレス倍増！」が発生します
- `life.html` — 人生ゲーム風の遊びモード
- `style.css` — レスポンシブデザイン、サイコロやルーレットのアニメーション
- `app.js` — SVG植物、盤面、ゲーム進行

## 現在の実装

- SVGで描画したドクダミの植物モチーフ
- アニメーション付きサイコロ
- 就活用・遊び用の別ページ
- 相談イベントの50/50ルーレット
- スマートフォン向けレイアウト

## 今後の候補

1. プレイヤー人数と名前の設定
2. 複数プレイヤーのコマ
3. 同じルームのプレイヤー間でゲーム状態をリアルタイム同期
4. イベントカードやお金・職業など人生ゲームの要素
5. ゲームのリセット・ルーム参加コード

## リアルタイム共有について

現在はブラウザ内だけで動くシングルプレイヤー版です。複数端末で同じ盤面とターンを同期する機能は、リアルタイム通信の方式を決めてから追加します。WebSocketは通信方式であり、WebSocket接続を受け付けるサーバーまたは対応サービスが必要です。
